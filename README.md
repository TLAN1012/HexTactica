# HexTactica — 戰團戰役

> 小隊制六角戰棋單機戰役。率領你的戰團,推進十關劇情,把血狼劫掠團趕出河谷。
> 靈感來自經典六角戰棋手遊,規則與程式皆為原創實作。

## 這是什麼

你指揮一支戰團,一支小隊 = 一群士兵。傷害看的是「還有幾個人活著」——
滿編的劍盾兵一擁而上很痛,被打殘後輸出也跟著掉。打贏關卡拿金幣、招兵、
升級,再去啃下一場更硬的仗。核心樂趣在於兵種相剋與地形卡位:讓騎兵繞後
獵弓手、用長槍陣接住衝鋒、搶佔森林減傷。

## 快速上手

### 一場戰鬥怎麼打

- **每支小隊每回合能啟動一次**:可以「移動 + 攻擊」,也可以只移動或只攻擊。
- **攻擊即結束該隊的啟動**,所以先想好走位再出手。
- 點自己的小隊 → 看到可移動範圍與可攻擊目標;**直接點敵人**,小隊會自動走到最佳位置再打。
- 出手前會顯示**攻擊預覽**(預計打死幾人、對方會不會反擊),看清楚再決定。
- 我方全部動完 → 換敵方 AI 行動。把敵軍全滅就勝利,自己全滅就敗北。

### 反擊要記住

- **近戰**會被防守方反擊(每隊每回合一次);**遠程射擊不吃反擊**——所以能射就先射。
- **長槍兵**防守時**先制反擊**(先捅你再挨打),而且**克制騎兵**並讓衝鋒失效。別拿騎兵去撞槍陣。
- **騎兵**助跑越遠衝鋒越痛;**弓手被貼臉**就只能用小刀,務必用步兵/長槍護住後排。

### 補兵迴圈(戰役經營)

1. **打贏拿金幣**(首次通關全額,重刷同關只有四折)。
2. 戰損會**留到下一關**——回**軍營**花金幣補滿減員的小隊。
3. 金幣夠就**招募**新小隊(最多 6 隊)或養精銳:擊殺敵兵得經驗,滿門檻升級(最高 5 級,每級 +10% 血/傷、滿編 +2 人)。
4. 帶著更強的戰團回戰役地圖,挑下一關。

詳細數值與公式見 [RULES.md](./RULES.md);架構見 [DESIGN.md](./DESIGN.md)。

## 本機開發

```bash
npm install      # 安裝依賴
npm run dev      # 開發伺服器(http://localhost:5173)
npm run build    # 建置 production 靜態網頁(tsc -b + vite build)
npm run lint     # ESLint 檢查
npm run preview  # 本地預覽 build 結果
```

推到 `master` 後由 GitHub Pages 自動部署。
