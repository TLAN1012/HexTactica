# HexTactica — 六角戰記

> 小隊制六角戰棋。從維京長船到三十八度線,以你的指揮改寫歷史。
> 精緻華麗的哥德風少年少女美術,所有插畫由自架的 Qwen-Image 生成。

## 戰役

| 戰役 | 內容 |
|---|---|
| **1066 王冠之爭** | 富爾福德 → 斯坦福橋 → 黑斯廷斯。你是英格蘭:先替國王爭取時間,再奇襲挪威王,最後在森拉克山脊守到天黑。前一戰的戰果會影響下一戰 |
| **奇幻外傳:碎顱之戰** | 原版十關獸人戰役,招兵升級的經營玩法 |
| 百年戰爭、拿破崙戰爭、韓戰 | 即將推出 |

每場歷史戰役都有照真實戰場畫的地圖、劇情對話、指揮官立繪,以及各自的勝利條件
(殲滅、斬首、守住陣地、撐過時限),援軍會在史實的時刻抵達。

## 難度

| 難度 | 說明 |
|---|---|
| 見習 | 敵軍較弱、AI 常失誤、獎金多,**可以悔棋** |
| 騎士 | 標準。AI 會集火、保護弓手 |
| 領主 | AI 會評估你的威脅範圍、懂得**斬首**你的指揮官,敵軍多一級 |
| 傳奇 | 敵軍更強更精、錢更少 |

難度隨時可以在戰役選單更改。

## 怎麼打

- **一隊 = 一群士兵**,傷害 = 存活人數 × 單兵傷害,被打殘輸出就掉。
- 每隊每回合**移動 + 攻擊**一次(或只做其一),攻擊就結束這隊的行動。
- 點自己的部隊 → 金色是能走的格、紅色是能打的敵人(虛線 = 要先走過去)。
  滑鼠懸停看攻擊預覽、點下去就打;**觸控:點一下預覽、再點一下出手**。
- **近戰會被反擊,遠程不會**。長槍先制、克騎;騎兵衝鋒越跑越痛,但**撞不動盾牆、衝不上山坡**。
- **盾牆**:家臣兵、民兵、維京人並排站,互相掩護承傷更少。
- **指揮官(♛)**:本隊與相鄰友軍傷害 +15%;很多戰役指揮官倒下就輸。
- 地圖可以**拖曳、滾輪或雙指縮放**,「全圖」一鍵回到整張地圖。

詳細數值見 [RULES.md](./RULES.md);架構見 [DESIGN.md](./DESIGN.md)。

## 本機開發

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # vitest:劇本完整性、傷害公式、存檔、AI 對打模擬
npm run build    # tsc -b + vite build
npm run lint

# 平衡報告:AI 雙方各打 N 場,印出各難度勝率
BALANCE=1 N=20 npx vitest run scripts/balance.test.ts

# 美術(需要家用 tailnet 的畫室):生成缺少的圖,刪掉某張就會重畫
python3 scripts/art/gen-art.py [類別或檔名關鍵字]
```

推到 `master` 後由 GitHub Pages 自動部署。
